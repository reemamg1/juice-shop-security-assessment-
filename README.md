📌 Project Overview

A hands-on web application security assessment conducted using OWASP Juice Shop, an intentionally vulnerable application designed for cybersecurity training.

This project explores common web application security vulnerabilities through controlled testing, HTTP traffic inspection, and security analysis.

🎯 Project Objectives

* Explore common web application vulnerabilities.
* Perform SQL Injection testing.
* Investigate Cross-Site Scripting (XSS).
* Analyze HTTP requests and responses using Burp Suite.
* Document security observations and recommend mitigation techniques.

🔍 Security Testing Results

1. SQL Injection (SQLi)

A login test involving SQL Injection resulted in successful authentication.

Observation: Successful login was observed during the test. The exact input and steps still require documentation.

Recommended Mitigation: Use parameterized queries and prepared statements.

2. Cross-Site Scripting (XSS)

A JavaScript alert dialog appeared after submitting a crafted search input.

Observation: JavaScript execution was observed. The exact execution context and vulnerability subtype have not yet been confirmed.

Recommended Mitigation: Apply context-aware output encoding and avoid unsafe HTML insertion.

3. HTTP Traffic Analysis

Burp Suite Community Edition was used to inspect HTTP requests and responses generated by the application.

Observation: A login request using the POST method was captured, along with an HTTP 200 OK response.
